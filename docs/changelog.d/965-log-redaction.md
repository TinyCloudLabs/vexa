- **Redacted meeting diagnostics (TC-965).** INFO logs now use counts, lengths, durations, per-meeting speaker indices, and short hashes of internal meeting IDs instead of participant names, transcript/caption text, meeting URLs/native codes, or raw exception messages. Python startup, warning, process, and thread exceptions and bot fatal events use the same sanitized boundary; AWS sync output is discarded rather than buffered. `DEBUG_ADMISSION` is debug-image-only, count-only, and not set by the deployed ptx compose.
