- **Redacted meeting diagnostics (TC-965).** INFO logs now use counts, lengths, durations, per-meeting speaker indices, and short hashes of internal meeting IDs instead of participant names, transcript/caption text, meeting URLs/native codes, signed URLs, tokens, SQL parameters, object keys, or exception bodies. Meeting API, gateway, rollback CLI, and admin API entrypoints configure handler-based JSON sanitizers before app construction; Uvicorn access logs are disabled. Python warnings and process/thread exceptions and bot fatal events use sanitized boundaries; AWS sync output is discarded rather than buffered. `DEBUG_ADMISSION` is explicit opt-in, count/locale-only, and unset in deployed ptx compose.
