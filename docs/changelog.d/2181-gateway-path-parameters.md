- **Consistent gateway path parameters (TC-2181).** Forwarded parameters are quoted per segment across meeting, calendar, agent, and MCP endpoints. Decoding validation is capped at four rounds; values still decoding after that are refused with 400. Dot segments and controls on matched routes are refused; encoded separators in agent/MCP tails are refused with 400. On single-segment routes, separators are decoded before routing and can produce 404 or match another existing template with that template's own scope check. Validation remains before authentication and the per-user rate limiter: invalid parameters can answer 400 ahead of 401/403 without consuming that rate limit. Existing scope declarations and bare-nickname Google Meet lookup identities are unchanged.
