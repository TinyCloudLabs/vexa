- **Bot checkpoint screenshots are off by default (TC-2181).** Screenshot requests targeting `/app/storage/screenshots` or its descendants return no pixels and write no file unless the bot process explicitly sets `VEXA_CHECKPOINT_SCREENSHOTS=1` before browser launch. Keep the flag unset or `0` in production; opting in restores the existing unsanitized checkpoint behavior.
