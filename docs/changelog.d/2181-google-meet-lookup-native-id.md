- **Accept Google Meet lookup links (TC-2181).** Meeting creation derives the bare lookup nickname as its native ID and treats a null ID as absent. Lookup paths with semicolon parameters or extra segments are refused rather than reinterpreted as dashed meeting codes; valid lookup identities and existing rows are unchanged. Calendar imports use the same parser and honor their auto-join policy independently of a caller application's link validation. See [calendar auto-join and rollback handling](/how-to/calendar-sync#auto-join-for-imported-meetings).
